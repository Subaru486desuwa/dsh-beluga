# dsh-personal-chat

One community plugin for personal conversations inside DeepSeek Harness, alongside unchanged Work.

Implementation is in progress. The target compatibility baseline is the unmodified DSH 0.2.1-rc.3 release. Installation commands and supported provider combinations will be documented after clean-package acceptance.

- Architecture: [plugin-owned chat](docs/adr/0001-plugin-owned-chat.md)
