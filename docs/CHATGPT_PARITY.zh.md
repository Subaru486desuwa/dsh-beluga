# ChatGPT 网页能力对齐清单

记录 Beluga Chat 对照 ChatGPT 网页版的差距和实现顺序。整理于 2026-11-06，2026-11-08 按设计讨论重排批次，依据下方官方资料的搜索结果和指南页；帮助中心页面无法直接读取，套餐差异未核对。兼容目标改为日常使用的 Harness 版本线；单侧栏由插件在打开 Chat 时盖住工作区列表实现（ADR 0005），与 Work 的互通见 ADR 0006。

## 实施顺序

1. **记忆修复**：记忆摘要的三个已知问题。
2. **信息架构**：Chat 与 Work 平级、单侧栏、设置合并、聊天列表排序与活动状态、思考指示、来源扩展、归档语义。
3. **Work 互通**：记忆查询、Work 记录、交给 Work。
4. **Projects**。
5. **个性化**。
6. **自动标题**：已提前随信息架构完成。

其余缺失能力排在这些之后。

## 暂不复刻

| 能力 | 原因 |
|---|---|
| 实时语音 | 需要实时模型和音频通道，与 Harness 的模型路由不匹配 |
| 群聊、共享项目 | 插件目前只服务单一所有者，需要新的授权边界 |
| 公开分享链接 | Host 只在本机运行，导出文件更符合这个前提 |
| 锁定聊天 | 单一所有者的本机场景价值低 |
| 购物、虚拟试穿、连接第三方账号 | 依赖官方服务 |
| Intelligent UI | 模型自带能力，插件无法单独实现 |
| 追问建议 | 每条回复都多花 token，对日常办公帮助小；记忆摘要页的建议保留 |
| 个性化的临时聊天 | 临时聊天不读不写记忆是已验收的承诺 |
| 星标或优先级字段 | 置顶加按活动状态排序已覆盖 |

## 需要决定

- **数据分析：** 运行代码会放宽规格里 “Chat 不能执行代码” 的约束，要先验证 Harness 沙箱能否用于 Chat。
- **图片生成：** DeepSeek 路由目前没有对应能力，需要配置额外的图片服务。
- **搜索导入的历史：** 目前不搜索，因为界面承诺导入历史只有在续聊时才发送给模型。要纳入搜索，需要先改这条承诺。
